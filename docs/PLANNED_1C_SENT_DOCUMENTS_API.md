# Отложено: список отправленных документов и получение исходных XML для 1С

Дата обсуждения: 01.10.2026.
Статус: 01.10.2026 пользователь согласовал реализацию. Методы реализованы локально;
контракт и ограничения: [API_1C_SENT_REPORTS.md](API_1C_SENT_REPORTS.md).
Развертывание и живая проверка на сервере пока не выполнены.

## Метод 1 — список отправленных документов

Вход: ИНН организации и период поиска в днях, например:

```json
{"inn": "9728133958", "days": 30}
```

Ожидаемый результат: все отправленные за это время документы организации,
идентификатор документа СБИС, дата отчёта/отправки и текущий статус.
При реализации уточнить различие даты документа и даты отправки.
Предложенная трактовка периода поиска — последние N дней по дате отправки,
а не отчётный квартал/год внутри декларации.

Предложенные дополнительные поля: название и вид отчёта, отчётный период,
номер корректировки, исходный код статуса, понятное описание статуса,
ошибки и причины отказа, если доступны.
Учитывать все страницы выдачи СБИС.

## Метод 2 — исходный XML отправленного отчёта

Запрос пользователя: по идентификатору документа и дате скачать сам
отправленный XML и вернуть его в 1С.
Предложенный вход также содержит ИНН для выбора кабинета и сертификата:

```json
{"inn": "9728133958", "sbis_doc_id": "...", "sent_date": "2026-09-28"}
```

Возвращать исходные байты XML в Base64 и имя файла, сохраняя кодировку.
Это XML отправленного отчёта, а не квитанции или извещения.
Предложение для НДС: основной XML и отдельный список приложений
(книги покупок/продаж), чтобы можно было восстановить весь комплект.

## Предложенные общие требования

- Защита существующим токеном API для 1С.
- Сохранение скачанных XML на сервере и повторная выдача из локальной копии
  для экономии прокси-трафика.
- Использование существующей инфраструктуры СБИС и сертификатов.
- Пути маршрутов, точный контракт, ограничения периода, пагинация ответа
  и правила обновления статусов ещё не согласованы.

## Открытый вопрос

Первая ручка должна возвращать все отправки из кабинета СБИС, включая ручные,
или только документы, отправленные через наш сервис?
Согласован список по ИНН без ограничения отправками нашего сервиса.
